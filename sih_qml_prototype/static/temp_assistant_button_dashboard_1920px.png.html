● Multi-Method Model Interpretability & Feature Attribution

🔬 Dual Explainability Framework (Permutation XAI vs SHAP)

Permutation feature importance operates model-agnostically across both the quantum circuit and classical baselines, while SHAP provides rigorous game-theoretic Shapley attributions for the classical model.

⚛ Hybrid VQC (Permutation ΔAUC)

Measures global drop in test ROC-AUC when quantum angle-encoded PCA features are shuffled.

📊 Classical Baseline (Permutation ΔAUC)

Same permutation perturbation applied to the 4-feature classical logistic regression baseline.

🌟 Classical Baseline (SHAP Values)

Mean absolute Shapley values ($\mathbb{E}[|\phi_i|]$) capturing game-theoretic marginal log-odds impact.

Scientific Distinction between Methods:
  • Permutation Feature Importance (Global Sensitivity): Measures the drop in classification performance ($\Delta\text{AUC}$) when a feature is corrupted across the test distribution. Model-agnostic and universally valid for both classical algorithms and quantum statevector circuits.
  • SHAP (Shapley Additive exPlanations): Computes additive feature attributions based on cooperative game theory. Quantifies each feature's contribution towards shifting the model prediction from the base expected value to the final log-odds.
