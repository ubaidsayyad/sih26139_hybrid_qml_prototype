● Hospital & Clinical System Interoperability

REST API Reference (v1)

Programmatic interface for hospital electronic medical records (EHR/HIS) and laboratory management systems (LIMS) to execute real-time hybrid quantum oncological diagnostics.

🔑 Authentication Header

All protected endpoints require an API Key supplied in the X-API-Key request header.

X-API-Key: qml_live_<your_secret_key>

⏱ Rate Limiting Policies

To ensure fair resource allocation on quantum simulation engines:

  • /api/v1/predict: 30 requests / minute per API key
  • /api/v1/history: 60 requests / minute per API key
  • Exceeded requests receive HTTP 429 Too Many Requests.
POST

/api/v1/predict

Requires API Key

Executes real-time simultaneous inference across the 4-Qubit Hybrid Variational Quantum Classifier and the Classical Fair Baseline for a single patient feature vector. Automatically persists the inference into the clinical audit database under your practitioner account.

Request Payload (JSON)

{
  "features": [0.2845, -0.1492, 0.0821, -0.0195],
  "dataset": "Breast Cancer Wisconsin (Diagnostic)"
}

Success Response (200 OK)

{
  "status": "success",
  "prediction_id": 42,
  "quantum": {
    "prediction": "Malignant",
    "probability": 0.8850,
    "confidence": 0.8850
  },
  "classical": {
    "prediction": "Malignant",
    "probability": 0.9520,
    "confidence": 0.9520
  },
  "consensus": true,
  "dataset": "Breast Cancer Wisconsin (Diagnostic)",
  "timestamp": "2026-08-28T14:45:00Z"
}
GET

/api/v1/history

Requires API Key

Retrieves a paginated list of all diagnostic inferences performed by the authenticated practitioner account. Strict isolation guarantees that doctors can only view their own prediction records.

Query Parameters

  • page (integer, default: 1): Page number.
  • per_page (integer, default: 20, max: 100): Records per page.
  • result (string, optional): Filter by Malignant or Benign.

Success Response (200 OK)

{
  "status": "success",
  "page": 1,
  "per_page": 20,
  "total": 14,
  "pages": 1,
  "predictions": [
    {
      "id": 42,
      "dataset": "Breast Cancer Wisconsin (Diagnostic)",
      "model_used": "both",
      "prediction_result": "Malignant",
      "confidence": 0.8850,
      "created_at": "2026-08-28 14:45:00"
    }
  ]
}

● Standardized HTTP Status Codes

Error Codes & Responses

HTTP Code Name Trigger Condition
200 OK Success Request executed successfully.
400 Bad Request Invalid Input Missing features payload, non-numeric values, or invalid dimension.
401 Unauthorized Authentication Required Missing or invalid X-API-Key header.
429 Too Many Requests Rate Limited Exceeded 30 calls/minute rate limit.
500 Internal Error Server Failure Unexpected backend error (stack traces are sanitized).
